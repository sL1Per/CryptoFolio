HOW TO USE IN XCODE

  1. Open AppIcon.svg in Sketch, Figma, or macOS Preview
  2. Export as PNG at: 1024×1024, 512×512, 256×256, 128×128, 64×64, 32×32, 16×16 (and @2× variants)
  3. In Xcode, open Assets.xcassets → AppIcon
  4. Drag each PNG into the matching size slot
  5. For the macOS single-layer option, drag the 1024×1024 PNG into the 1024pt @1× slot
